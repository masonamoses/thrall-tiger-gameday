One-time setup

  1. Go to developer.spotify.com/dashboard, log in with your Spotify Premium account, and create an app.
  2. Under APIs, check Web API and Web Playback SDK.
  3. Add the Redirect URI shown above, then save.
  4. Copy the app's Client ID into the box above and tap Connect.
  5. For anyone else's Spotify login (up to 5 people), add their email under User Management.

Game-day tips

  1. Laptop: this page becomes its own player ("Game Day DJ" in the device list). Plug the laptop into the PA.
  2. Phone/iPad: open the Spotify app and play anything for a second so it shows up as a device, then pick it here. Plug that phone into the PA.
  3. Turn Crossfade off and Autoplay off in Spotify settings so nothing bleeds in after a cue.
  4. Keyboard: 1–9 fire the first nine cues, Space fades out, Esc hard-stops.
